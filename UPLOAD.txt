PixelGBA — static deployment checklist

Upload the complete repository contents together. Runtime files remain flat at the
site root; LICENSES/, tests/, scripts/, and .github/ may stay in their directories.
Do not upload only the original 17-file bundle: check.html, sw.js, licensing, and
support files are now part of the maintained deployment.

REQUIRED RUNTIME FILES
  index.html              app shell
  styles.css              app styles
  app.js                  app logic
  config.js               flat runtime path map
  pixelgba-worker.js      cancellable ROM/backup worker
  manifest.webmanifest    installable-app metadata
  assets/                 generated 180/192/512 px app icons
  cheats-db.js            revision-scoped cheat presets and provenance
  loader.js               patched EmulatorJS loader
  emulator.min.js         EmulatorJS runtime
  emulator.min.css        EmulatorJS styles
  version.json            runtime version metadata
  en-US.json              runtime localization
  mgba.json               core build metadata
  mgba-wasm.data          primary mGBA core
  mgba-legacy-wasm.data   fallback mGBA core
  extract7z.js            archive worker
  extractzip.js           archive worker
  libunrar.js             archive worker
  libunrar.wasm           archive worker WASM
  sw.js                    versioned offline cache
  build-info.js            generated cache ID and asset manifest
  check.html               deployment self-check
  LICENSE                 project/EmulatorJS GPL-3.0 text
  THIRD_PARTY_NOTICES.md  component notices and source links
  SECURITY.md             deployment header guidance
  docs/                   device matrix and cheat provenance
  LICENSES/               additional license texts

GITHUB PAGES
  1. In Settings -> Pages, select GitHub Actions as the source.
  2. Merge to main or run the Deploy GitHub Pages workflow manually.
  3. The workflow tests, assembles, and deploys the exact .pages artifact.
  4. Its verify job checks every deployed asset and content-derived build ID.
  5. Open https://<username>.github.io/<repository>/check.html.
  6. Continue only when every runtime file passes.

LOCAL USE
  Windows: double-click serve.bat
  macOS/Linux: run ./serve.sh
  Node.js: node serve.js 8080

Then open http://127.0.0.1:8080/. Do not open index.html through file://.
The local launchers bind only to the loopback interface.

DEVELOPER VERIFICATION
  npm ci
  npm run build:icons  (required after changing the icon generator)
  npm run build:meta   (required after changing any cached runtime asset)
  npm run test:all
  npm run build:pages

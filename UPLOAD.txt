PixelGBA — FLAT upload (no folders!)

Upload these 17 files TOGETHER, all at the repo root.
There is nothing to nest, nothing to drag folder-by-folder.

    1  index.html              (~20 KB)  <- opens the app
    2  styles.css               (29 KB)
    3  app.js                   (49 KB)
    4  cheats-db.js              (7 KB)
    5  loader.js                (13 KB)
    6  emulator.min.js         (417 KB)
    7  emulator.min.css         (25 KB)
    8  version.json            (126 B)
    9  en-US.json               (10 KB)
   10  mgba.json               (118 B)
   11  mgba-wasm.data         (1.01 MB)  <- the emulator core

   17  serve.bat              (3 KB)     (local play only; optional on GitHub)

STEPS
  1. github.com -> + -> New repository -> name it -> Create
  2. Add file -> Upload files -> select ALL 17 (Ctrl+A) -> drag in -> Commit
  3. Settings -> Pages -> Source: Deploy from a branch
     Branch: main   Folder: / (root)   -> Save
  4. Wait ~1 minute, then open:  https://<your-username>.github.io/<repo>/
  5. Drop in a .gba ROM and play.

VERIFY (10 seconds)
  The repo's file list should show index.html AND mgba-wasm.data AND
  emulator.min.js as flat files - no subfolders at all.
  Opening the Pages URL and pressing F12 -> Console should show no red errors.

WHY THIS WORKS WITHOUT FOLDERS
  index.html carries a tiny path-map (PIXELGBA_FLAT_PATHS) that tells the
  emulator where each engine file is, so everything can sit side by side.
  Tested end-to-end: boots in ~6.7 s, saves, cheats, 25/25 automated checks,
  zero console errors.

PLAY LOCALLY INSTEAD (no GitHub)
  Double-click serve.bat -> browser opens http://localhost:8080

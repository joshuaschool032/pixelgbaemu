Tips

  • Battery saves are compatible with VBA-M, mGBA, visual retro handhelds and real cartridges via a dumper.
  • Save states are not portable to other emulators — use the .sav for that.
  • Back up before big cheats: export the .sav, then go wild.

Quick start

  1. Get a ROM — a .gba file of a game you own. PixelGBA ships with none, for obvious reasons; dump your own cartridge with a tool like GB Operator or rip from a cart you legally own.
  2. Drop it in — drag the file onto the drop zone (or click Choose ROM file). The game boots immediately.
  3. Save — save states from the Saves tab, battery saves are automatic.
  4. Cheat — open the Cheats tab, pick your Pokémon game's preset or paste a GameShark / CodeBreaker code.

ROM not loading?

  • .gba, .agb, .bin, .zip, .7z and .rar copies are supported — this is a GBA emulator, not a DS or SNES one.
  • If the screen stays black, try unzipping the ROM first.
  • Extremely large (32 MB+) patched ROM hacks are fine; the engine caches them in your browser's storage after the first load.

House rules

  • Turn walking-through-walls cheats off before saving — you can save yourself inside a wall.
  • Two cheats that write the same address fight each other. Enable one at a time.
  • If a code does nothing, enable the game's Master Code first.

Saves, states & backups

Save states

5 slots per game + validated .pgstate exports. Imports verify the ROM, core version, size and checksum before loading; legacy raw .state files still work.

Battery saves

The game's own save file (.sav). Event-driven auto-sync keeps two rolling previous copies and restores the latest when you load the ROM again.

Where it lives

All ROMs, saves and states stay in your browser's private storage on this PC (IndexedDB + localStorage). Clearing site data wipes them — export anything precious.

A full backup includes cached ROMs, battery saves, states, cheats, favorites and settings. Restore validates every binary checksum before replacing this site's PixelGBA data.
